# Discord Integration

Send new [Formboost](https://formboost.app/) form submissions to Discord.

## Setup

1. Open your form in the [Formboost dashboard](https://dashboard.formboost.app/).
2. Open **Integrations**.
3. Select **Discord**.
4. Add the Discord destination or webhook requested by Formboost.
5. Save the integration.
6. Submit a test form and verify the message arrives in Discord.

Your form endpoint remains:

```text
https://formboost.app/f/YOUR_ENDPOINT_ID
```

For the latest setup instructions, see the [official Formboost documentation](https://formboost.app/docs).
