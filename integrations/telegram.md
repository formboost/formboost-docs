# Telegram Integration

Send new [Formboost](https://formboost.app/) form submissions to Telegram.

## Setup

1. Open your form in the [Formboost dashboard](https://dashboard.formboost.app/).
2. Open **Integrations**.
3. Select **Telegram**.
4. Configure the Telegram destination requested by Formboost.
5. Save the integration.
6. Submit a test form and verify the notification arrives.

Your website continues sending submissions to:

```text
https://formboost.app/f/YOUR_ENDPOINT_ID
```

For current configuration details, see the [official Formboost documentation](https://formboost.app/docs).
