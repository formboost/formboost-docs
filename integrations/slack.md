# Slack Integration

Send new [Formboost](https://formboost.app/) form submissions to a Slack channel.

## Setup

1. Open your form in the [Formboost dashboard](https://dashboard.formboost.app/).
2. Open **Integrations**.
3. Select **Slack**.
4. Connect or configure the Slack destination shown in the dashboard.
5. Save the integration.
6. Submit a test form and verify the message arrives in Slack.

Your website still posts to the normal Formboost endpoint:

```text
https://formboost.app/f/YOUR_ENDPOINT_ID
```

No Slack-specific frontend code is required.

For the latest setup instructions, see the [official Formboost documentation](https://formboost.app/docs).
