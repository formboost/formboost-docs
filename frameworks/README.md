# Formboost Framework Guides

Use [Formboost](https://formboost.app/) with any frontend framework that can submit an HTTP form or `POST` request.

Canonical docs: [https://formboost.app/docs](https://formboost.app/docs)

## Available guides

- [HTML](./html.md)
- [React](./react.md)
- [Next.js](./nextjs.md)

The core endpoint format is always:

```text
https://formboost.app/f/YOUR_ENDPOINT_ID
```

For many frameworks, no SDK is required. You can use a standard HTML `<form>` or submit JSON with `fetch`.
