# Contributing to Formboost Docs

Thanks for helping improve the [Formboost](https://formboost.app/) documentation.

## Source of truth

The canonical documentation lives at [https://formboost.app/docs](https://formboost.app/docs). Changes in this repository should stay aligned with the live product behavior.

## Guidelines

- Keep examples simple and copy-paste friendly.
- Use `https://formboost.app/f/YOUR_ENDPOINT_ID` in generic submission examples.
- Spell the product name **Formboost**.
- Do not include API keys, credentials, production secrets, or real customer submission data.
- Prefer realistic dummy values such as `jane@example.com`.
- Link relevant pages back to [https://formboost.app/](https://formboost.app/) or the canonical docs when useful to the reader.
- Avoid keyword stuffing or repetitive backlinks.

## Reporting documentation issues

Open a GitHub issue with the affected page, expected behavior, and the correction you recommend.
